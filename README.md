## ◇ About the Project

**AE Global Group** is a redesigned study-abroad experience focused on reducing confusion during the international education journey.

Instead of presenting students with another crowded education portal, the website uses a clean, editorial and product-focused experience.

The core principle is simple:

> **Stop guessing. Start applying with clarity.**

Students can understand their options, explore universities and destinations, prepare their applications and receive guidance throughout the study-abroad journey from one consistent platform.

## ✦ UI / UX Principles

### 01. One Purpose Per Section

Every section should communicate one primary idea.

### 02. Progressive Disclosure

Students should not receive all available information at once.

Information appears as it becomes relevant.

### 03. Visual Hierarchy

```text
HEADLINE
   ↓
Context
   ↓
Primary Action
   ↓
Supporting Information
```

### 04. Motion With Purpose

Animations should help users understand the interface.

Examples:

* Scroll reveal
* Counter animations
* Sticky storytelling
* Card transitions
* Destination interactions
* Globe movement
* Button micro-interactions
* Section transitions

Animations should never exist purely as decoration.

## ✦ Local Development

Clone the repository:

```bash
git clone <repository-url>
```

Move into the project:

```bash
cd aeglobal
```

Install dependencies:

```bash
npm install
```

Create your local environment file:

```bash
cp .env.example .env.local
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## ◇ Environment Variables

Use `.env.example` as the local development template.

```env
OPENAI_API_KEY=
```

Never commit production secrets to the repository.

Production environment variables should be configured through the deployment platform.
